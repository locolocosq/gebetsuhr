# Nurkreis Website (uebernommen aus xaloH/bilal-gebetsuhr)

Diese Website wurde 1:1 aus dem Repo https://github.com/xaloH/bilal-gebetsuhr
(Branch `web/scroll-experience`) uebernommen. Sie ist ein eigenstaendiges,
noch unfertiges Scroll-Erlebnis fuer ein separates Markenkonzept ("Nurkreis",
Platzhaltername) und NICHT identisch mit der bisherigen Gebetsuhr-Website
unter `docs/index.html`.

## Starten (lokal)

    node scripts/server.mjs

## Bauen (statisch, keine Abhaengigkeiten)

    node scripts/build.mjs

Ergebnis liegt danach in `dist/`.

## Offene Punkte laut Handoff (siehe briefs/handoff-notes.md)

- Name "Nurkreis" ist nur ein Platzhalter.
- Alle Produktbilder sind KI-Visualisierungen, keine echten Fotos.
- Kein Impressum, kein Datenschutz, kein echter Kontaktweg hinterlegt.
- Religioese Reviewpunkte (Requisiten, Stationsnamen, Ring-Bedeutung) noch offen.

Vor einer Veroeffentlichung sollten diese Punkte geklaert werden.
